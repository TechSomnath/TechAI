# 🚀 TechAI — Full-Stack AI Chat Application

TechAI is a modern, full-stack AI chat application inspired by ChatGPT, built **completely from scratch** with a strong focus on performance, security, and clean UI/UX.

This project demonstrates real-world full-stack development skills including authentication, protected routes, global state management, API structuring, and AI-powered conversations.

---

## 🧠 What is TechAI?

TechAI allows users to have intelligent, real-time conversations with an AI assistant using GPT.  
It includes full authentication, protected chat access, and a responsive modern interface.

---

## ✨ Key Features

- 🤖 Chat with an AI assistant (ChatGPT-like experience)
- 🔐 JWT-based authentication (Login / Register)
- 🛡️ Protected routes & secure cookies
- 💬 Chat history management
- ✅ Schema-based form validation using Zod
- 🔄 Global state management with Redux Toolkit
- 🎨 Clean, modern & responsive UI
- 🚨 Smart error handling & toast notifications
- ⚡ Optimized backend APIs

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- DaisyUI
- React Router
- Redux Toolkit
- Redux Thunk
- React Hook Form
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Redis
- JWT Authentication
- Validator

### Validation & Security
- Zod (Schema-based validation)
- JSON Web Tokens (JWT)
- Secure HTTP-only cookies

---

## 🧩 Architecture Overview

- **Frontend** handles UI, authentication flow, protected routes, and global state
- **Backend** manages users, authentication, AI chat APIs, and data persistence
- **Redux Toolkit** manages chat state and user sessions
- **JWT** ensures secure access to protected resources
